# ספריית הסקילס של Yair

ספרייה נבחרת לסוכני AI: סקילס שמתוחזקים כאן וקישורים לסקילס ממקורות אחרים.

**האוסף כולל 40 סקילס מאושרים בשישה תחומים**, כולם כקישורים למקורותיהם. תשעה מפנים לגרסאות היסטוריות משום שהסקיל המקורי הוסר או אורגן מחדש במקור. כל קישור מקובע לגרסת Git מאומתת, כך שהתוכן אינו משתנה בלי בדיקה. קישור חיצוני אינו עותק שנשמר כאן, והתקנה אינה מבטיחה שכל כלי ההפעלה זמינים אצלך.

בסבב השני נוספו סקילס לרעיונאות, בניית סצנות, ניתוח סגנון, חוויית קריאה, הקמת ותחזוקת פרויקט סיפור, עריכת וניתוח וידאו, תמלול, אפקטים קוליים, סקירת מאמרים ומחקר GitHub. להתקנת `story-init` יש לצרף את `story-maintenance` מאותה גרסת מקור. סקילס האודיו של ElevenLabs דורשים גישה לשירות ומפתח API אישי.

בסבב השלישי נוספו עשרה סקילס ל־FFmpeg, גרפיקה על וידאו דיבור, כתוביות, סרטוני הסבר, גרפים, איתור סקילס, הכנת והנפשת דמויות, סקירת ספרות ופודקאסטים. סקילס HyperFrames מפנים גם לסקילס ליבה מחוץ לתיקייה; יש להכין את חבילת התלויות לפני הפעלה. סקירת הספרות והפודקאסטים דורשים התאמה מסביבת DeerFlow.

אפשר לבקש מסוכן בעל גישה לרשת ולקבצים:

> קרא את AGENTS.md ואת catalog.json במאגר https://github.com/yairdash/ai-skills. מצא סקיל שמתאים למשימה שלי, הסבר מה הוא דורש והתקן אותו בפרויקט הנוכחי. אם זה קישור חיצוני, השתמש במקור שמופיע ברשומה.

## מבנה

`skills/<skill-name>/` מכיל סקיל מלא שמאוחסן כאן. `catalog.json` מכיל גם רשומות מסוג `external`, שהקבצים שלהן נמצאים במאגר המקור. הקטגוריות נמצאות בקטלוג, כך שהעברת סקיל בין קטגוריות אינה משנה את כתובתו.

התוכן העיקרי מיועד לסוכנים במחשב. התאמה לצ׳אט ולענן מצוינת בנפרד ובכפוף לבדיקה. פרטי גישה אינם נשמרים במאגר.

## תחזוקת הקטלוג

נדרש Node.js 22 ומעלה:

```sh
node scripts/catalog.mjs validate
node scripts/catalog.mjs render
```

יש לשמור גרסת מקור וייחוס לכל סקיל שמועתק או מותאם. [מדיניות מקורות ורישיונות](PROVENANCE.md).
