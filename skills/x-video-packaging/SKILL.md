# Skill: X Video Packaging Pack
Version: 1.0.0

## Inputs
- A video the current environment can inspect, a playable proxy, or a concrete scene description. Input limits depend on the tool; do not assume a universal file-size ceiling.
- Optional: specific audience niche or creative intent.

## Workflow
1. Visual & Cinematic Audit: Analyze opening frame/hook (0-2s), primary action beat, lighting, mood, and pacing.
2. Audience Fit: Identify core target clusters on X (e.g., AI Filmmaking, VFX, Sci-Fi/Horror, Cinema Craft).
3. Generate 3 Distinct Post Variants:
   - Variant A (Story-first): Narrative intrigue, character tension, or lore hook.
   - Variant B (Visual/Curiosity-first): Sharp, punchy, leading with an impossible or striking visual question.
   - Variant C (Craft/Process-first): Cinematic build, directing choices, or technical generation angle.
4. Discovery Layer: 3-5 restrained, high-intent hashtags and search keywords.

## Output Schema
- Content ID / Working Title:
- Hook Frame & Audience Entry:
- Post Options for X:
  - Option 1 (Story): [Copy]
  - Option 2 (Visual Hook): [Copy]
  - Option 3 (Craft/Behind-the-Scenes): [Copy]
- Hashtags & Search Keywords:
- Thumbnail / First-Frame Recommendation:
## Evidence and scope

Inspect the video only with tools available in the current environment. If only a description is available, label observations as based on that description; do not claim to have watched the clip. Do not invent the tools, model, settings or production process behind it. Ask for a missing process detail only if it is needed for the craft variant.

Return drafts and thumbnail/first-frame recommendations. This skill does not publish posts, upload media, or authorize external messaging. Treat hashtags and keywords as editorial suggestions, not evidence of current trends or a guarantee of reach. Use the user's language and tone unless specified otherwise.
