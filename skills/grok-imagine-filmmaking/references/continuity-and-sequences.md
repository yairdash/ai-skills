# Continuity, extension, and sequences

## Decide: extension or new shot?

| Situation | Use |
| --- | --- |
| The same camera keeps rolling and time is continuous | Video extension |
| The camera changes angle, distance, or side of the line | Fresh video using the continuity package |
| The existing clip has identity/style degradation | Fresh video from the best approved still/reference package |
| Only a visible element needs changing inside a successful clip | Video edit |

Do not force a reverse angle through an extension. It solves the wrong continuity problem and encourages camera, action, and identity drift at once.

## Extend a clip

State that the action begins precisely at the source clip's final frame. Continue one movement or reaction only.

```text
Continue seamlessly from the final frame. NOA takes two more slow steps to the right, then looks back once.
Keep the same framing, camera speed, lighting, identity, charcoal bomber, ORBITAL case, and metro platform. Do not reset the pose, cut to a new angle, or introduce a new object.
```

Use short extensions. Review every join. When accumulated compression, face drift, or changed production design becomes visible, extract the best recent frame and restart a fresh shot rather than extending indefinitely.

## Edit a clip

Use video edit for a contained correction that must retain the rest of an existing short clip. Describe the requested change as narrowly as possible:

```text
Keep the performance, camera movement, identity, wardrobe, setting, and lighting unchanged. Change only the plain black case to the established matte-black ORBITAL case with one centred white logo.
```

If a clip needs a new performance, shot size, or camera language, regenerate it rather than repeatedly editing it.

## Multi-shot production pattern

1. Lock the project brief and reference package.
2. Make a location/style master and an approved character keyframe.
3. Plan coverage as separate shots: master/establishing, action or dialogue coverage, and reaction/detail only where story value justifies it.
4. Generate the first shot from the strongest suitable start image; generate new angles with the shared continuity package.
5. Use extension only within a single continuous setup.
6. Export individual selected clips for final pacing, audio, and transitions in an editor.

## Shot handoff format

```text
SHOT 03 — NOA notices the case
Purpose: let the viewer see the case before her reaction.
Mode: reference-to-video
References: identity, wardrobe, hero prop, location master
Action: she stops beside the case; her eyes move to it.
Camera: locked-off medium shot, shoulder height.
Audio: room tone only.
Continuity: retain identity, wardrobe, prop dimensions and location design.
Recovery: if hands/prop drift, generate a static insert from the prop master and cut to it.
```
