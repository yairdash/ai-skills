# Project assembly and workspaces

## Use a project workspace for organization, not as a substitute for shot design

Use Grok Projects, library search, and parallel work to keep references, notes, stills, and clips together. For the full Canvas / Agent Mode workflow, read `canvas-agent-workflow.md`.

## Recommended order for a short scene

1. Write the project brief and continuity bible.
2. Generate or collect identity, wardrobe, prop, and location masters.
3. Make a small shot list and create static keyframes.
4. Animate only approved panels/keyframes.
5. Branch variations rather than overwriting a successful result.
6. Assemble selected clips externally when precise pacing, transitions, sound mixing, or titles matter.

## External post is normal

Export selected individual shots to CapCut, Premiere, DaVinci Resolve, or the user's NLE when they need exact cuts, professional sound, narration, music, grading, graphics, or reliable lip-sync replacement. A short sequence need not be stitched inside Grok to be considered successful.
