# Evidence for the current project

This public edition includes no private production findings or property rankings. Before choosing a property, inspect evidence supplied for the current project or create a dated research record. If none exists, mark native recall, voice, set fidelity and production transfer untested. Do not invent previous successes.

Record the tested model, date, exact prompt, inputs, duration, aspect ratio, output and review. Separate observed results from community reports and predictions. A short identity probe is not evidence that a longer multi-character scene will work.

Use one visible speaker at a time when identity separation is uncertain; explicitly describe every silent listener. Test one named uncertainty at a time and preserve failures alongside successes.
