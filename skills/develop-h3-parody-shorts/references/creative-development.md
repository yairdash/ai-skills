# Creative Development

Build character bibles from sourced personality mechanics, relationships, speech tendencies, visual anchors, recurring environments, forbidden copied dialogue, and uncertainty notes. Describe voice through observable speech behavior, not biometric actor imitation.

Add a compact provenance line to each bible, concept card, storyboard, and prompt: label its material as `project-demonstrated`, `official`, `community-reported`, `LoRA-derived`, or `inferred`. Translate any retained LoRA trigger into ordinary descriptive language; include it only when it helps the intended shot and never because it is a trigger word.

Every concept specifies: familiar character engine, transplanted world, original conflict, transformation/commentary angle, hook-escalation-reaction beats, frame-one visual hook, and originality check.

Use supplied examples only to identify abstract comedic patterns. Create new dialogue, conflicts, shot order and timing rather than transferring a source scene.

Enter mid-task or mid-conflict. Make dialogue reveal character and advance conflict. Differentiate vocabulary, sentence shape, priorities, and evasions. Use subtext and reactions rather than catchphrases. Keep the spoken load plausible and staging simple enough for H3.

For dialogue scenes, prefer one visible speaker per shot. Define each listener by name, clothing, screen position, behavior, and closed lips. Do not use a generic phrase such as "a listener" when identity duplication would be costly. If several characters must speak, separate their lines into clean shot windows and keep the cast small.

Favor a single strong contradiction: a recognizable character logic colliding with a new mundane rule. Use one visual hook, one escalation, and one readable reaction. Complexity spent on extra characters, portals, inset television images, or simultaneous actions competes with identity and lip-sync reliability.

For every storyboard beat specify subject, subject motion, scene and overlays, spatial framing, and camera. Mark non-applicable aspects `N/A`. Repeat identity anchors verbatim and define the ending reaction.

Reject concepts dependent on copied dialogue, an existing setup/payoff sequence, recreated composition, or a minor noun swap. The conflict and viewpoint must remain new when source references are removed.
