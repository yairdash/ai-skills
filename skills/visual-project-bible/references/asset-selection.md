# Choosing foundation images

## Start from an uncertainty, not a shopping list

Ask what would force the project to redesign or lose continuity later. Favor images that settle recurring identity, distinctive silhouette, spatial relationships, a manipulated prop or an essential material/style treatment. Appearance frequency alone is insufficient: an object seen once may still need a precise design if it drives a reveal or hand interaction.

An image earns a place when it answers a distinct question. Record its purpose in one sentence. If deleting it would leave no meaningful uncertainty, reuse another image or defer it. A larger pack is not inherently more complete.

## Image roles

| Role | Useful evidence | Add another image when |
|---|---|---|
| Character identity | Clear face/features or nonhuman distinguishing structure, readable silhouette; suitable framing and lighting | An important side/back feature, age/state change or occlusion is unresolved by the existing evidence |
| Wardrobe/body | Full figure, proportions, costume construction, footwear and attached items | A story-required outfit/state differs, or a detail must be readable for interaction |
| Expression | Character-specific facial range | An expression changes important anatomy/design or the project needs a reusable expression sheet; do not make one for every emotion automatically |
| Location master | Architecture, layout, entrances, scale, important surfaces and material relationships | Another view resolves hidden geography needed for action, or an approved layout is difficult to infer |
| Spatial diagram | Adjacency, entrance/exit, object positions, scale | Spatial relationships matter more than a beauty image can establish; a simple text/diagram may be sufficient |
| Hero prop/product | Shape, construction, distinctive marks and scale | A manipulation, opening/closing mechanism, reverse side or changed state must be designed |
| Style/material anchor | Observable rendering medium, palette relationships, texture, light treatment and degree of realism | A separate visual regime is intentional; do not use one attractive mood image to dictate every identity and composition |
| Scale/relationship check | Relative heights and contact between already defined entities | Independent references leave size, reach, seating or grip ambiguous; this is a neutral design test, not automatically a story frame |

Combine identity and wardrobe if one readable image answers both. Separate them when face detail, costume complexity or the intended tool makes that more useful. A multi-view sheet is an optional design artifact; it is not universally better than separate views and may leak panels or confuse geometry in later generation.

Neutral reference lighting often reveals design better than dramatic light. Retain the intended material and visual medium, but avoid occlusion, cropped defining features or strong perspective distortion when they conceal the property being designed. A moodboard explores direction; an approved style anchor specifies the selected direction. Keep them labeled separately.

## Priority and dependencies

- **Required:** without this evidence, a named identity/design/spatial decision remains unresolved for the planned use.
- **Conditional:** needed only if a specified scene, view, state or provider requirement is adopted.
- **Deferred:** attractive exploration without a current production need.

Prioritize based on consequence of error, reuse, uncertainty and creation cost. Use these as judgment criteria, not an invented precise score. Dependencies point to specific image IDs or established decisions. Avoid circular dependencies: use a rough textual specification or a provisional layout to establish the first anchor, then refine it.

Example: a courier carries a distinctive sealed cylinder through one greenhouse. The first wave might need a character identity/body reference, a cylinder master and a greenhouse layout/master. A separate expression sheet, ten outfit variants and a skyline are unjustified unless the brief introduces those needs. If an approved character image already covers face and costume, reuse it rather than generating both again.

## States and variants

Keep one entity ID across deliberate states: `CHAR-01` with `wardrobe-work`, or `PROP-01` with `closed` and `open`. Each state needs an image only if it changes important visible design. Do not mistake ordinary pose variation for a new identity. Record which features persist and what changes. If two existing images disagree, do not average them silently: identify the conflict and use the approved authority or present a proposed resolution.

When requirements are vague, start with a small proposed package and state which later decisions would expand it. Completeness is measured against the current brief, not every hypothetical future shot.
