# תחזוקת הספרייה

## הוספת סקיל או קישור

אפשר לבקש: ״בדוק את הקישור הזה והצע להוסיף אותו לקטגוריית וידאו״. הסוכן יבדוק את המקור, SKILL.md, הדרישות והייחוס, ויציג המלצה. סקיל חיצוני נכנס כברירת מחדל כקישור. גרסה אישית שמעתיקים ומשנים דורשת בדיקת רישיון ותיעוד השינויים.

רשומת קישור כוללת `id`, `name`, `category`, `description_he`, `kind: external`, `source` עם `repository`, `path`, `url` ו־`revision`, וכן `requirements`, `compatibility` ו־`review_status`. גרסת המקור היא SHA כאשר אומתה; ערך null פירושו שאין עדיין גרסה מאומתת. סקיל מקומי משתמש ב־`kind: hosted` וב־`path: skills/<name>`.

אחרי עריכת catalog.json מריצים `node scripts/catalog.mjs validate` ואז `node scripts/catalog.mjs render`, בודקים את ההבדלים ושומרים Commit. הקטלוג הנוח לקריאה נגזר מקובץ JSON; לא עורכים אותו בנפרד.

## עדכון לפי בקשה

האוסף הראשון מקבע כל קישור ל־commit SHA מאומת. פריט המסומן `historical-snapshot` שומר סקיל שהנתיב שלו אינו זמין כיום במקור. לפני עדכונו בודקים אם הוחלף, אוחד או הוסר; אין לשנות את הקישור אוטומטית ל־main או להחליף את הסקיל ללא הסבר למשתמש.

אפשר לבקש: ״בדוק עדכונים לסקילס שהתקנתי בפרויקט הזה, והראה לי מה השתנה״.

1. מזהים את המקור והגרסה שהותקנה; אם לא נרשמה גרסה, מציינים זאת ולא מנחשים.
2. בודקים את הגרסה העדכנית ואת השינוי בהוראות, בסקריפטים ובתלויות.
3. שומרים את המצב הקיים ב־Git או בתיקיית גיבוי נפרדת, כולל שינויים אישיים וקבצים שאינם מנוהלים ב־Git.
4. מחילים את העדכון הנבחר, בודקים ומעדכנים את תיעוד הגרסה.

עדכון קישור בקטלוג ועדכון עותק שכבר הותקן במחשב הם פעולות נפרדות. השינוי ב־GitHub אינו מעדכן אוטומטית מחשבים אחרים. אפשר להשתמש ב־`npx skills check` לבדיקת עדכונים להתקנות שהכלי מנהל; בודקים את הפלט לפני הפעלת עדכון.

## חזרה לגרסה קודמת

אפשר לבקש: ״החזר את הסקיל לגרסה שלפני העדכון האחרון״. במאגר שפורסם משתמשים ב־Git revert ל־Commit המתאים ושומרים גם את ההחזרה בהיסטוריה. במחשב היעד משחזרים את תיקיית הסקיל מהגיבוי או מתקינים מהגרסה המתועדת, ובודקים שוב.

## בדיקה לפני העלאה

בודקים את רשימת הקבצים וההבדלים, מפעילים את אימות הקטלוג, ומוודאים שמידע אישי ופרטי גישה אינם נמצאים בתוכן או בהיסטוריה שמעלים. `.gitignore` אינו מסיר סודות שכבר הוכנסו להיסטוריה. מאגר ציבורי מקבל רק את תיקיית הפרסום הציבורית.
